# Guide Region — Sights of Almaty

**Language: English throughout.** A responsive tourism website based on the provided Figma screenshots.

## Open the website on Mac or Windows

1. Download `guide-region-english.zip`.
2. Double-click the ZIP to extract it.
3. Open the extracted `guide-region` folder.
4. Double-click **`index.html`** to launch the website in your browser.

Keep `index.html`, `style.css`, and `script.js` together in the same folder.

The website includes a mobile navigation menu, Top Places cards, Routes, tourist tips, a trip-planning form, PDF checklist export, and a light/dark theme switcher.

**Internet connection:** Required for the illustrative online photos, Google Fonts, and PDF-generation library. These photos are examples, not the exact assets from the Figma file.

## Publish using GitHub Pages

1. Create a **public** GitHub repository.
2. Upload `index.html`, `style.css`, `script.js` and `README.md` into the repository root.
3. Make at least three meaningful commits during your work, e.g. `feat: add semantic layout`, `feat: implement responsive cards`, `feat: add PDF trip planner`.
4. Open **Settings → Pages → Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then save.
5. Open the GitHub Pages URL after deployment completes.

## Privacy and functionality

PDF generation happens in the browser. Email and phone data entered in the form are included only in the saved PDF and are not sent to a server or to an email address.
